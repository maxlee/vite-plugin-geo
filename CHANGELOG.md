# Changelog

All notable changes to `vite-plugin-geo` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0]

### Added

- **Vite+ support**: Works in Vite+ (`vite-plus`) projects, including `lazyPlugins`. The consumer matrix now builds a Vite+ 1.6.0 project from the packed tarball.
- **`package.json` `homepage` fallback for the site domain**: When neither `geo({ domain })` / `--domain` nor `package.json` `domain` is set, an absolute `http(s)` `homepage` is used as the site origin across Vite, Astro, `generate`, and `verify`. It must be origin-only like `domain`. Relative values such as `"."` are ignored.

### Changed

- **Source layout**: Runtime files moved to `src/`. The public entry points (`vite-plugin-geo`, `vite-plugin-geo/astro`, and the `vite-plugin-geo` bin) are unchanged.
- **Astro output handling**: Astro redirect pages are excluded from generated outputs.
- **Sitemap detection**: Existing sitemap files are recognized regardless of `.xml` extension case, and sitemap entries are sorted by code unit for deterministic output.

## [0.2.2]

### Changed

- **Markdown mirror content extraction**: Mirrors no longer convert the full HTML `<body>` unconditionally. Content extraction now prefers `<main>`, then a single page-level `<article>`, and falls back to `<body>` only when neither exists (or when `<main>` is empty). When falling back to `<body>`, `nav`, `aside`, `footer`, and heading-free `header` elements are stripped so site navigation and footers do not leak into mirrors.
- **Mirror front structure**: Mirrors prepend `# <title>` and `> <meta description>` (omitting empty values) and deduplicate the first body `<h1>` when it matches the page title.
- **Asset normalization**: Inline `<svg>` elements are removed. Relative `<img src>` URLs resolve to absolute URLs against the HTML page's public URL (for example, `images/flow.png` inside `docs/index.html` resolves to `https://example.com/docs/images/flow.png`), while anchor `href` attributes remain unchanged.
- **Empty-content fallback**: When neither `<main>` nor `<body>` yields readable body text, the plugin still writes a valid mirror containing the ownership marker plus any available title and description.

### Migration Notes

- Snapshot or diff tests against generated `.md` mirrors must update their baselines.
- To keep full-page or custom Markdown output, set `llmsMdMirror: false` or provide a hand-written Markdown file linked via `<link rel="alternate" type="text/markdown">`. With the default `fileConflict: 'preserve'`, user-owned files remain untouched.

## [0.2.1]

### Added

- **`fileConflict` option (`'preserve' | 'error' | 'overwrite'`, default `'preserve'`)**: Controls how existing user-owned companion files (`llms.txt`, `feed.xml`, `humans.txt`, `sku.md`, and `*.md` mirrors) are handled across Vite, Astro, and CLI (`--file-conflict`). `sitemap.xml` and `robots.txt` continue using `sitemapConflict` and `generateRobots`.
- **`preservedFiles` reporting**: Preserved user files are excluded from `generatedFiles` and reported separately in CLI summaries and return values.

### Fixed

- **Non-destructive defaults for user companion files**: Astro `astro:build:done` and `vite-plugin-geo generate` now preserve existing user-owned `llms.txt`, `feed.xml`, and other companion files with a warning instead of aborting the build.
- **Ownership marker precision**: Ownership detection now matches exact format-specific `Generated by vite-plugin-geo` markers rather than loose substring checks, preventing user files that mention the plugin name in prose from being overwritten.
- **Vite `public/` conflict detection**: Vite builds now scan `public/feed.xml`, `public/sku.md`, and `public/**/*.md` so user static assets are not silently overwritten.

### Migration Notes

- Projects that relied on v0.2.0's fail-on-conflict behavior as a CI gate should set `fileConflict: 'error'`.

## [0.2.0]

### Changed (Breaking)

1. **Public-path Markdown mirrors**: Under `prettyUrls: true`, `about.html` now maps to `about.md` instead of `about.html.md`, and the home page maps to `index.md`. Generated files, `llms.txt` links, and injected `alternate` links share one resolver. Update external links if you previously referenced `*.html.md`.
2. **Duplicate routes fail by default**: When multiple HTML files resolve to the same public route, the build throws and lists the conflicting files (`routeConflict: 'error'`). Set `routeConflict: 'first'` or `'last'` to opt into deterministic deduplication.
3. **Absolute URL `base` values throw**: Full CDN URLs in Vite or Astro `base` (such as `https://cdn.example.com/`) are rejected instead of producing malformed `/https:/...` paths. Set `routeBasePath` explicitly.
4. **Visible external Sitemap preservation**: Detected third-party Sitemaps are preserved with a warning printing the filename, source, `<loc>` count, and up to 3 sample URLs. Setting `generateSitemap: true` without an explicit `sitemapConflict` policy throws an actionable error.

### Added

- **`vite-plugin-geo verify` subcommand & `verifyGeoOutput` API**: Read-only post-build verification of `dist/` covering Sitemap `<loc>` entries, `.html` leaks, intermediate path prefixes, file mapping, `robots.txt` `Sitemap:` reference, canonical URLs, `llms.txt`, `feed.xml`, and Markdown mirrors (recursing Sitemap indexes up to 5 levels).
- **Machine-readable reports (`--report json|sarif`, `--report-file`)**: Emits JSON (`schemaVersion: "1.0"`) or SARIF 2.1.0 for GitHub Code Scanning.
- **CI severity gates (`auditFailOn`, `--fail-on-audit`, `--fail-on-verify`, `--verify`)**: Turn build diagnostics or post-build verification into hard CI gates.
- **Per-page HTML hreflang (`hreflangFromHtml`)**: Extracts `<link rel="alternate" hreflang="...">` per page for Sitemap `xhtml:link` entries, adding a `<html lang>` self-reference when missing without fabricating `x-default`.
- **`lastmodIgnore` and `lastmodResolver`**: Exclude generated pages from `lastmod` lookups, aggregate missing-Git warnings, and resolve per-page W3C Datetime values programmatically.
- **Expanded static audit rules & `debug` summary**: Checks `.html` internal links under `prettyUrls`, invalid mirror paths, orphan pages, and `hreflang` reciprocity/self-reference.

## [0.1.5]

### Added

- **Default non-blocking build diagnostics (`audit: true`)**: Runs static page and discovery checks across Vite, Astro, and CLI (`--audit`, `--no-audit`, `--audit=true|false`) without failing builds or writing extra files.

### Fixed

- **User `robots.txt` preservation**: Hand-written `robots.txt` files (such as `public/robots.txt` in Astro) are preserved byte-for-byte by default instead of failing the build, while `generateRobots: true` still guards against silent overwrites.

## [0.1.4]

### Changed

- Implemented `llms.txt` v2 single-scope discovery (`rel="describedby"` and `rel="alternate" type="text/markdown"`) and `append` / `replace` Markdown mirror naming.
- Removed legacy `llms-full.md`, `llms-ctx.txt`, and `llms-ctx-full.txt` outputs and options.
- Changed default `lastmodStrategy` to `'none'` and removed Sitemap `priority` and `changefreq`.
- Added standalone `generateRobots` control; non-root `routeBasePath` scopes skip `robots.txt` by default.
- Added Atom `self` link and stable canonical URL `<guid>` to RSS 2.0 feeds; omitted `pubDate` when no reliable page timestamp exists.
- Updated `sku.md` support to the `1.0.0-beta` pure Markdown specification and removed legacy YAML draft options, `blockGoogleExtended`, and `stability*` options without compatibility shims.
